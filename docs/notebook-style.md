# Notebook and Example Standard

Use these conventions when adding material to this repository.

1. **One purpose per file.** Name the file after the technique or outcome it demonstrates.
2. **Start with context.** State the data source, goal, and expected output in the first Markdown cell or module docstring.
3. **Keep setup explicit.** List required packages and configuration; never embed credentials or personal cookies.
4. **Use clear Python.** Prefer small functions, descriptive names, request timeouts, and `response.raise_for_status()`.
5. **Finish with a takeaway.** Record limitations, ethical considerations, and the next technique to practice.

Before committing a notebook, clear temporary checkpoints and remove any private output or secrets.
